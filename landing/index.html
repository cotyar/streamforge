07 / NATIVE CDC

Database changes,
not another estate.

Point StreamsForge at Postgres or SQL Server, run streaming SQL over the change feed, and sink the result back to a database. Native CDC is built into the host: no Kafka cluster or Connect layer required for these two dialects.

Operator truth. A replication slot can pin WAL; SQL Server CDC retention can discard history; delivery is at-least-once. StreamsForge preflights those hazards—it does not pretend they disappear.

08 / CRDT + OFFLINE EDGE

Keep working
when the link doesn’t.

Offline sessions reconcile to one net result on reconnect. Replay is idempotent; bounded counters can keep a hard inventory limit even when replicas spend concurrently.

  • Yjs-compatible documents merge concurrent edits character by character.
  • Escrow counters preserve a distributed, offline bound.
  • SQL compensation turns an invalid merged state into a normal streaming workflow.
  • Presence is live per host process with automatic TTL eviction.

Available on the Orleans runtime. Dapr stores the kind but deliberately refuses to start it.
